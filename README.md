# 툰 이미지 ZIP 다운로더

`index.html` 하나로 동작하는 웹 도구입니다. 링크를 넣으면 `id="toon_img"` 안의 이미지를
1번부터 끝까지 순서대로 받아 `01.jpg, 02.jpg, …` 로 ZIP 하나에 묶어 저장합니다.

## 실행
- `index.html`을 내려받아 더블클릭(크롬) 하거나
- GitHub Pages 주소로 접속 (Settings → Pages → Branch: main / root → Save)

## 사용
1. 웹툰 페이지 링크 입력 → **ZIP으로 다운로드**
2. 안 되면: 페이지 소스(Ctrl+U) 붙여넣기
3. 그래도 안 되면: **북마크 버튼**을 북마크바로 끌어다 놓고, 웹툰 페이지에서 눌러 실행 (로그인 필요한 사이트도 가능)
