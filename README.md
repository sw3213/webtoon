# 웹툰 전 회차 자동 다운로더 (Python)

1화 링크 하나만 넣으면
- 각 화의 `id="toon_img"` 안 이미지를 **1번부터 마지막까지** 순서대로 받아 화마다 ZIP 하나로 저장하고
- **다음화**를 따라가며 **마지막 화(또는 원하는 화)까지** 자동으로 받습니다.
- **이미 받은 화는 건너뜁니다.** 중간에 끊겨도 다시 실행하면 이어서 받습니다(받다 만 화는 빠진 이미지만 받음).

## 처음 한 번만
1. https://www.python.org/downloads 에서 Python 설치 — 첫 화면의 **"Add python.exe to PATH" 꼭 체크**
2. 이 저장소에서 `webtoon_downloader.py`, `실행.bat` 두 파일을 같은 폴더에 받기

## 실행
- **윈도우:** `실행.bat` 더블클릭 → 1화 링크 붙여넣기 → 엔터 → 몇 화까지(그냥 엔터 = 끝까지)
- **명령어:**
  ```
  python webtoon_downloader.py "1화링크"          # 마지막 화까지
  python webtoon_downloader.py "1화링크" -n 30    # 30화까지
  ```
  (필요한 라이브러리는 처음 실행할 때 자동 설치됩니다)

## 결과
```
웹툰다운로드/
  _다운로드기록.json          ← 받은 화 기록 (지우면 처음부터 다시 받음)
  작품명/
    001 작품명 1화.zip        ← 안에 001.jpg, 002.jpg ...
    002 작품명 2화.zip
```

## 옵션
| 옵션 | 설명 |
|---|---|
| `-n 30` | 30화까지만 |
| `--next number` | 다음화 버튼을 못 찾을 때: 주소의 마지막 숫자를 +1 하며 진행 |
| `--id 아이디` | 이미지 영역 id가 `toon_img`가 아닐 때 |
| `--out 폴더` | 저장 폴더 변경 |
| `--name 이름` | 작품 폴더 이름 직접 지정 |
| `--delay 3` | 화 사이 쉬는 시간(초) |

## 안 될 때
- 1화에서 바로 멈춤 → `--next number`
- "toon_img 영역이 없습니다" → 로그인/성인인증이 필요한 사이트이거나 이미지를 자바스크립트로 불러오는 사이트라 이 방식으로는 받을 수 없습니다.
- 저작권 작품은 개인 소장용으로만 사용하세요.
