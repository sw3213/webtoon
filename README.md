# 툰 다운로더

1화 링크만 넣으면
- 각 화의 `id="toon_img"` 안 이미지를 **1번부터 마지막까지** 순서대로 받아 화마다 ZIP 하나로 저장하고
- **다음화**를 따라가며 **마지막 화(또는 원하는 화)까지** 자동으로 받습니다.
- **이미 받은 화는 건너뜁니다.** 중간에 멈춰도 다시 시작하면 이어서 받습니다(받다 만 화는 빠진 이미지만 받음).

## 처음 한 번만
1. Python 설치: https://www.python.org/downloads (설치 중 "Add python.exe to PATH" 체크)
2. 이 저장소를 ZIP으로 받아 압축 풀기 (Code → Download ZIP)

## 실행
**`실행.bat` 더블클릭** → 브라우저에 다운로더 화면이 열립니다 → 1화 링크 넣고 **다운로드 시작**

- 검은 창은 프로그램 본체입니다. 닫으면 종료돼요. (브라우저 탭은 닫아도 다운로드 계속됨)
- 필요한 라이브러리는 처음 실행할 때 자동 설치됩니다.

## 결과
```
웹툰다운로드/
  _다운로드기록.json        ← 받은 화 기록 (지우면 처음부터 다시 받음)
  작품명/
    001 작품명 1화.zip      ← 안에 001.jpg, 002.jpg ...
    002 작품명 2화.zip
```

## 안 될 때
- 1화에서 바로 멈춤 → "다음 화 찾기"를 **주소 숫자 +1** 로 바꿔서 다시 시작
- "toon_img 영역이 없는 페이지" → 로그인/성인인증이 필요하거나 이미지를 자바스크립트로 불러오는 사이트라 받을 수 없습니다.

## 파일
| 파일 | 설명 |
|---|---|
| `실행.bat` | 더블클릭용 |
| `webtoon_gui.py` | 화면(UI) |
| `webtoon_downloader.py` | 다운로드 엔진 (명령 창에서 `python webtoon_downloader.py "1화링크" -n 30` 으로도 사용 가능) |

저작권 작품은 개인 소장용으로만 사용하세요.
